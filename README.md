# 个人自介网页 · 课程作业提交说明

## 一、项目简介

本项目是一个**纯前端、零依赖的个人自介单页网站**，使用原生 HTML / CSS / JavaScript 实现。所有样式与脚本均内联在单一 `index.html` 中，照片与证书以 base64 内嵌，**不加载任何外部资源**，在国内任意浏览器中双击即可打开。

页面以「幕式叙事」组织内容，共 **12 幕**，依次呈现：姓名寄语 → 关键数据 → 个人简介 → 成长经历 → 项目作品 → 能力技能 → 教育背景 → 荣誉证书 → 未来规划 → 兴趣充电 → 互动小测 → 联系方式。

- 插入**个人证件照**作为头像，置于首屏 Hero 区，配合光晕与灯笼点亮效果突出主体；

## 四、创意设计与交互体验（对应要求 3）

围绕「由夜入晨」的视觉叙事，设计了多层次的交互体验：

- **星门入场动画**：进入页面先经历一段沉浸式开场——星空汇聚、星核点击充能（进度 0→100%）、尘埃汇聚、爆炸闪光与轻微震屏，营造仪式感；
- **幕式滚动叙事**：12 幕一屏一幕切换，带 `01/12` 计数、右侧圆点导航与「下一幕」按钮，支持空格 / 方向键翻幕；
- **滚动视差**：近景与远景星空分层，随滚动差速位移，增强纵深感；
- **深浅色主题切换**：一键切换并带全屏淡入淡出过渡，状态记忆于本地；
- **鼠标聚光灯**：光斑缓动跟随 + 四周暗角，强化氛围（可关闭）；
- **微交互细节**：双行反向无限跑马灯、可展开项目卡、点击夜空溅出星尘粒子、滚动揭示动画（分级延迟）；
- **趣味互动**：「充电」能量条（点选兴趣方式增长）、「同频小测」（3 题输出 4 种人格结果）、Web Audio 实时合成的环境音（雨 / 风 / 浪，无需音频文件）、留言随机回信；
- **无障碍与降级**：尊重 `prefers-reduced-motion` 自动关闭动效；移动端隐藏聚光灯与圆点导航、卡片纵向堆叠。

## 五、整体视觉与配色（对应要求 4）

- 采用**设计令牌（CSS 变量）**统一管理色彩、间距与字体，保证全局协调；
- 配色以**深蓝靛 + 青绿**为主，每幕沿「夜色 → 黎明」递进变化，既统一又有节奏；
- 毛玻璃、渐变文字、柔和光晕等手法提升质感，整体精致且不杂乱，体现审美把控。
